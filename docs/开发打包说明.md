# 开发与打包说明（Windows 端）

## 一、开发环境
- Windows 10/11
- Node.js 18+
- Python 3.10+
- 如需真实渲染 PPT 页面：LibreOffice 或 Microsoft PowerPoint
- 如需视频合成：FFmpeg

## 二、本地运行（开发模式）
### 1. 启动后端
```
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python -m app.main
```

### 2. 启动桌面壳
```
cd desktop
npm install
npm run dev
```

## 三、后续接入真实能力
- PPT 生成：`backend/app/services/ppt_generator.py`
- PPT 解析：`backend/app/services/ppt_parser.py`
- 解说词：`backend/app/services/script_gen.py`
- TTS：`backend/app/services/tts.py`
- 视频：`backend/app/services/video.py`

## 四、Windows 打包
- 桌面壳：`electron-builder`（NSIS）
- 后端：PyInstaller 或内嵌 venv
- FFmpeg：随安装包分发
- 最终产物：`.exe` 安装包 + 本地服务自动拉起

## 五、Mac 开发 Windows 端的补充说明
- 代码开发：Mac 完全可行
- 最终打包：推荐 GitHub Actions Windows Runner 或一台 Windows 机器
- 原因：PyInstaller/electron-builder 的 Windows 产物最稳的是在 Windows 环境出包
